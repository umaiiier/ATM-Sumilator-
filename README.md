🏦 Python ATM Simulator

A simple **ATM Simulator** built using Python. This beginner-friendly project allows users to perform basic banking operations through the command line.

## ✨ Features

- 🔐 PIN Authentication
- 💰 Check Account Balance
- 💸 Withdraw Money
- 💵 Deposit Money
- ❌ Invalid PIN Handling
- ⚠️ Insufficient Balance Check

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
ATM-Simulator/
│── atm.py
│── README.md
```

## 🚀 How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python atm.py
```

## 📝 Example

```
Welcome to the ATM

Enter your PIN: 123

Welcome to your account

1. Check Balance
2. Withdraw
3. Deposit

Enter your choice: 1

Your balance is: 1000
```

## 📖 How It Works

1. User enters the PIN.
2. The program verifies the PIN.
3. If the PIN is correct, a menu is displayed.
4. The user can:
   - Check balance
   - Withdraw money
   - Deposit money
5. The balance is updated after each transaction.
